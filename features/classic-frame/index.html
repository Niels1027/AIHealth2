核心页 · 古典版框改造

把「健康问书」三个核心页的圆角全部归零，卡片改用古籍版框式的直角细边。目标是让界面的形态跟上它已有的纸感、苔绿与宋体，读起来像一本书而不像一个 SaaS 后台。

版本 v0.3 日期 2026-08-29 出稿 SeanMa27 状态 已交接 v0.3

改动范围

动的是三个页面的外形，不碰任何接口、不碰任何交互逻辑、不碰文案：聊天页（侧栏、输入框、气泡、示例问题、来源卡）、知识库管理页（状态章、导入章、文档列表）、模型设置页（表单、分段控件、按钮组）。三处硬编码圆角在 globals.css，其余全是 Tailwind 的 rounded-* 类名替换。

关键拍板

D 号结论
D1方向取「全直角 + 版框细线」，不走微圆角、不走切角
D2双线版框只给章级容器 —— v0.3 由 D6 取代；控件用单线直角这一半仍然有效
D3圈点保留圆形——状态点、回答者标记点不参与归零；胶囊类（引用号、身份切换、进度条）跟着归零
D4本轮只动圆角与版框，阴影一律不动
D5用户气泡去掉指向性圆角后，补一条右侧苔绿竖线代替
D6章级容器用单线直角，线色比控件重一档（--color-line-strong）——层级靠深浅不靠条数，取代 D2 的双线画法

阅读体例

白底带边框的是正式帧——上线就长这样。浅灰底带左竖线的小字是标注，不进产品。每组对照左边标「现状」的是现网当前样子（取自载体文件），右边标「改后」的是本次交付。

是什么
章级容器的边框：直角、单线 1px #cfd5d0。它比控件用的 --color-line（#e5e7e3）重一档——层级靠线的深浅区分，不靠加线的条数。
交互
无。静态边框，不随悬停/聚焦变化。
数据来源
新增 token --color-line-strong，加进 globals.css 的 @theme；控件继续用现有 --color-line。
对应拍板
D6 章级容器用单线（取代 D2 的双线画法）
边界
内边距沿用现网 p-5，不需要额外加。窄屏下不降级。
/* globals.css @theme 新增一个 token */
--color-line-strong: #cfd5d0;

/* 章级容器：直角单线，比控件的线重一档 */
.frame { border: 1px solid var(--color-line-strong); }

/* 用法：rounded-2xl border-line → border-line-strong（去圆角、换线色）
   控件不动线色，继续用 border-line */
改过
v0.2 这里是双线版框（外 1px + 3px 留白 + 内 1px，仿古籍文武边）。Niels1027 在这个区块提「这个方形的不好」，沟通后确认是双线那圈线过重、在小卡片上显得脏。v0.3 收成单线，直角方向（D1）不变。留档见台账 D2 → D6。

二、什么不归零：圈点保留圆形

「圆角」和「圆形」是两回事。圆形的小点在古籍里本来就存在——那是圈点、句读。这类元素保留正圆，跟着归零会变成一排小方块，反而更不古典。

是什么
现网气泡用 rounded-br-md（右下角收小）指示「这句话来自右边的人」；归零后这个指向消失，改用右侧一条 2px 苔绿竖线承担同一职责，同时呼应古籍的眉批边线。引用号则靠描边把自己从正文数字里摘出来。

对应拍板
D5 气泡补右竖线；D3 引用号补描边
边界
气泡多行时竖线通高，不分段。引用号连续出现（[1][2]）时两个描边相邻，靠现有 margin:0 .12rem 分开，不额外加间距。

三、落地顺序

步做什么为什么是这个顺序
1globals.css：加 --color-line-strong、改三处硬编码圆角先把 token 立住，后面全是类名替换
2三个页面按上表批量替换 rounded-*；先手工挑出 7 处保留的 rounded-full圈点与胶囊类名完全相同，全局替换会误伤，必须先挑出来
3章级容器边框换 border-line-strong（控件保持 border-line）层级靠线的深浅，内边距沿用 p-5 不动
4三处补偿：气泡右竖线、引用号描边、两个 tab 激活项换 1px 线这三处是去圆角掉的信息，补完才算完成
边界
第 2 步是本次唯一的风险点——现网 7 处 rounded-full 里 4 处保留、3 处归零，类名一模一样，靠尺寸区分（h-1.5/h-2 是圈点，其余是胶囊）。改完对着「版框体系 · 什么不归零」那一屏逐个核。
易错
第 4 步给 tab 激活项加边框时，要给同组所有按钮预置 border border-transparent，只在激活项上换颜色。只给激活项加边会让它比兄弟宽 2px，切换时整组抖一下。引用号描边同理——现网 .cite-pill 要先补一圈透明边再换色。
