## 已拍板的约束

- **D1** 方向 = 全直角 + 版框细线。微圆角与切角两个方案已排除，不要"折中"回 2px
- **D2** 双线版框**只给章级容器**；按钮、输入框、侧栏项、来源卡、聊天输入框容器一律单线直角。控件套版框会满屏双线
- **D3** `rounded-full` 分治：状态圈点与回答者标记点（`h-1.5` / `h-2`，4 处）**保留正圆**；身份胶囊、引用号、进度条（3 处）归零。圈点是句读不是圆角
- **D4** 阴影一律不动。唯一例外是两处分段控件激活项（阴影与新外框重复，换 1px 实线），已在 `b-admin-import` 标注点明
- **D5** 用户气泡的 `rounded-br-md` 承担"指向发言人"，归零后**必须**补右侧 2px 苔绿竖线，不能只是删掉

## 开放问题（可自行判断）

- `.frame` 的实现手法：原型用 `box-shadow: inset` 双层。你若用伪元素或 `outline` + `outline-offset` 更顺手，只要视觉是「外 1px 深 + 3px 留白 + 内 1px 浅」即可，画法不限
- 步 3 的 `p-[21px]` 是原型量出来的值。若你的实现里版框占位不同，以「内线不贴正文」为准微调，不必死守 21px
- lucide 图标默认 `stroke-linecap="round"`，本轮**未纳入范围**。若你觉得直角界面配圆线端违和，可以提出来，但别顺手改——那会动到全站图标

## 一个坑，别踩

给 tab 激活项加边框、给引用号加描边时，**要先给同组所有元素预置 `border border-transparent`**，只在激活项上换 `border-color`。只给激活项加边会让它比兄弟宽 2px，切换时整组抖一下。原型自己踩过这个坑，已修（见 `b-impl-order` 的「易错」条）。
